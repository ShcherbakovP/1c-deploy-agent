# Примеры

Файлы в этой папке сняты с живого конвейера и обезличены: имена машин, баз, пользователей
и объектов заменены на вымышленные, тексты платформы и тайминги настоящие.

| Файл | Что это |
|---|---|
| `objects.xml` | Список объектов на захват/помещение (`test`, `commit`, `unlock`) |
| `MergeSettings.xml` | Настройки объединения для `/MergeCfg` (`test -Method mergecfg`) |
| `command-test.json` | Файл команды, который оркестратор кладёт в `<роль>/in/` |
| `response-ping.json` | Ответ на `ping`: версия, роль, платформа, установленные платформы |
| `response-pull.json` | Ответ на `pull`: снятие сеансов, обновление из хранилища, снимок `.cf` |
| `response-test.json` | Ответ на `test`: захват, локальная копия сборки, `MergeCfg`, `UpdateDBCfg` |
| `response-commit.json` | Ответ на `commit`: помещение и снятие остаточных захватов |
| `response-update-prod-hot.json` | Ответ на `update-prod -Mode hot`: бэкап, обновление, динамика применилась |
| `response-update-prod-error.json` | Ответ на `update-prod -Mode full`, когда сеансы снять не удалось: обновление не начато |
| `com-exec-check-com.vbs` | Скрипт для `com-exec`: диагностика COM-компоненты 1С на сервере |
| `mcp-args-execute_query.json` | Аргументы для `mcpq.py execute_query` |

## Сеанс доставки одной доработки

Так выглядит консоль рабочей станции. Оркестратор печатает строки лога с меткой цели и
JSON ответа целиком (здесь сокращён).

```
PS> powershell -File F:\deploy\deploy.ps1 ping
[2026-09-07 09:50:12] [test] Команда 20260907-095012-ping отправлена, жду ответ до 90 с.
[2026-09-07 09:50:17] [test] Ответ на 20260907-095012-ping: status=ok
{ "agent": "2.0", "role": "test", "host": "TEST-1C", "platform": "8.3.24.1808", ... }

PS> powershell -File F:\deploy\deploy.ps1 pull
[2026-09-07 09:51:03] [test] Команда 20260907-095103-pull отправлена, жду ответ до 5400 с.
[2026-09-07 09:54:11] [test] Ответ на 20260907-095103-pull: status=ok
[2026-09-07 09:54:11] [test] Снимок: artifacts/snapshot-20260907-095408.cf (SHA256 C849…4E4D, 54.8 МБ)

  (на рабочей станции из снимка собираются release-*.cf, objects-*.xml, MergeSettings-*.xml)

PS> powershell -File F:\deploy\deploy.ps1 test -Comment "Задача #123: сервис поиска по номеру документа"
ВНИМАНИЕ: команда 'test' изменяет ОБЩЕЕ хранилище конфигурации.
[2026-09-07 09:56:51] [test] Команда 20260907-095651-test отправлена, жду ответ до 3600 с.
[2026-09-07 10:00:33] [test] Ответ на 20260907-095651-test: status=ok
{ "note": "Объединено и применено. Объекты захвачены; проверьте тестовую, затем deploy commit.", ... }

  (проверка тестовой базы руками или автотестами)

PS> powershell -File F:\deploy\deploy.ps1 commit -Comment "Задача #123: сервис поиска по номеру документа"
ВНИМАНИЕ: команда 'commit' изменяет ОБЩЕЕ хранилище конфигурации.
[2026-09-07 10:06:57] [test] Команда 20260907-100657-commit отправлена, жду ответ до 3600 с.
[2026-09-07 10:07:52] [test] Ответ на 20260907-100657-commit: status=ok
{ "note": "Помещено в хранилище, остаточные захваты сняты.", ... }

PS> powershell -File F:\deploy\deploy.ps1 update-prod -Target prod -Mode hot
ВНИМАНИЕ: update-prod (режим hot) обновляет БОЕВУЮ базу из хранилища.
[2026-09-07 10:14:01] [prod] Команда 20260907-101401-update-prod отправлена, жду ответ до 5400 с.
[2026-09-07 10:15:41] [prod] Ответ на 20260907-101401-update-prod: status=ok
{ "mode": "hot", "backup": "prod-backup-20260907-101406.cf", "note": "База обновлена динамически, без завершения сеансов. ...", ... }
```

Если динамическое обновление не применилось (нужна реструктуризация), последний ответ приходит
со `status: error`, признаком `hotDynamicFailed: true` и текстом «Динамическое обновление не
применилось … СТОП — решение за человеком». Агент на `full` сам не переключается: `full`
завершает все сеансы, и это решение человека.

## Запрос к базе через MCP-транспорт

```
PS> powershell -File F:\deploy\deploy.ps1 mcp-start -Target test
PS> $env:MCP_EXCHANGE = 'F:\mcp-test'
PS> python F:\deploy\mcpq.py execute_query F:\deploy\examples\mcp-args-execute_query.json 120
```

Результат печатается в консоль и целиком пишется в `mcp-last.json` (консоль Windows
кириллицу часто портит, файл надёжнее).
