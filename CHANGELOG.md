# История изменений

## 2.0 (2026-09)

Первая публичная версия. Обезличенная и причёсанная редакция агента, который с июля 2026
обслуживает три контура: тестовый сервер с хранилищем, боевая база за шлюзом удалённых
рабочих столов и бухгалтерия без хранилища.

Что изменилось относительно внутренней версии 1.19:

- роль определяется по `hostPattern` из конфига, а не по зашитым именам машин;
- папка обмена задаётся параметром `-ShareRoot` (агент) и `-Root`/`DEPLOY_ROOT` (оркестратор);
- три обёртки над `1cv8 DESIGNER` сведены в одну, `ras`/`rac` вынесены в общий контекст;
- папки обмена MCP и имя обработки берутся из конфига, а не из таблицы в коде;
- транспорт MCP через тонкий клиент с `/Execute` удалён: форма обработки при таком запуске
  не открывается, остался только демон по COM;
- `mcp-daemon.vbs` хранится в UTF-8, агент конвертирует его в ANSI перед запуском;
- оркестратор сам отказывает в командах хранилища цели без `repoPath`;
- исключение внутри команды возвращается ответом `error`, а не роняет цикл;
- поиск других экземпляров агента смотрит на `-File …deploy-agent.ps1`, а не на любое
  упоминание имени в командной строке PowerShell;
- каталог локальной копии обработки MCP вынесен в конфиг (`mcpLocalDir`);
- в ответ `kill-sessions` добавлено число оставшихся сеансов, когда снять всех не удалось;
- папка `examples/` с обезличенными файлами команд, ответов, `objects.xml`, `MergeSettings.xml`
  и консольным сеансом доставки.

Внутренняя история до 2.0 (для контекста): v1.11 `com-check`; v1.13 `load-cf`;
v1.14 `mcp-start`/`mcp-stop`/`mcp-list` через COM-демон; v1.15 `build-epf`, `peek`,
`windows`, `screenshot`, `com-exec`; v1.17 `fetch`; v1.18 роль без хранилища
(`ext-list`/`ext-dump`/`ext-install`/`dump-cf`/`dump-dt`), `platformVersion: auto`;
v1.19 `repo-unbind`, учёт тонкого клиента в `windows`/`mcp-list`.
